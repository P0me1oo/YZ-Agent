# VLESS Reality 前置池

Node [v2.25.0](https://github.com/P0me1oo/YZ-Agent/releases/tag/v2.25.0) 已发布，配套面板 `1.106.2`、管理端 `0.77.0`；更新顺序和产物核验见[兼容矩阵](../YZ_COMPATIBILITY.md)。

详细管理步骤见[面板使用说明](../../YZboard/docs/load-balancer.md)。统一入口是面板生成的独立 `balancer` 实例，由机器发现流程启动；无需在服务器上安装额外 DDNS 程序，Cloudflare Token 只由面板保存。

入口在最高可用优先级内按新 TCP 连接轮询，内部透传标准 PROXY v2 来源；成员只信任面板下发的入口来源地址。状态变化只替换后续连接的候选集，已有连接不迁移。全部成员离线时关闭新连接，保持落地绑定，不自动直出。

新实例不需要用户名单也持续监听；不读取或重复上报用户套餐流量。原有两个核心负责成员的认证、来源检查、用户限制及流量统计。WG 多前置使用独立身份及地址，落地监听接受多个对端；普通单前置配置保持兼容。

本版只有 VLESS Reality TCP/RAW 入口，HY2 不参与前置池。两个核心目录和 Go 固定依赖不变，不使用本地核心路径替换。
