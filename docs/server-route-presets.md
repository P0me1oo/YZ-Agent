# 服务端路由分类与拦截顺序

Agent v2.44.0，配套 YZboard 2.25.0 / Dash 0.107.0。快捷预设、已有出口配置和使用边界见[面板路由说明](../../YZboard/docs/server-routes.md#快捷预设)。无核心或模块依赖升级，无数据库和协议字段变更。

## 分类数据

两种核心共用 `kernel.geo_data_dir` 下的 `geoip.dat`、`geosite.dat`。沿用缺失文件自动下载，已有文件不覆盖；下载加互斥，避免多个核心实例同时覆盖临时文件。sing-box 将分类转为带稳定标签的内联规则集，保留域名四种匹配方式、属性、网段及反选。只加载配置实际引用的文件；移除全部分类后不加载数据。

转换不合并域名和 IP 条件为“与”：同条面板路由里的地址任一命中即可，协议、端口和网络仍为“与”。已有自定义规则集（包括嵌套逻辑集）保持完整；重复引用只生成一份，重复准备不改变配置。生成标签与自定义标签冲突、无匹配分类或非法数据均报错。

Xray 的分类缓存仍由核心管理，sing-box 在生成配置时读取数据。本次不增加分类文件的后台更新；替换文件后按原配置应用／进程生命周期重新加载。高级结构化 sing-box 路由仍须使用明确地址或规则集，普通面板路由才享有分类转换。

## 执行顺序与已有出口

面板拦截先于中转；入口禁令覆盖入口直出与中转用户。非拦截规则位于中转之后，不能改写线路的落地。存在 IP 拦截时，Xray 使用按需 IP 解析，sing-box 在拦截前解析一次；不需要 IP 拦截的中转仍保留原始域名。Reality 防盗用、自定义规则和默认内网保护的优先级保留。

转发出口须来自已有的面板出站、本地出站、自定义配置文件或中转出站；未知标签、空标签和大小写不符会在配置校验阶段报错，不能静默变为默认直连。WARP 只作为已有标签引用，本程序不安装 WARP、不注册账户、不修改系统网络。

回退到旧 Agent 前，sing-box 分类路由应先移除或改成明确域名、网段；旧版本还会恢复中转先于面板拦截的顺序。
