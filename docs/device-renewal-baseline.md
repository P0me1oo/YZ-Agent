# 设备同步基线修复

维护者：P0me1oo。版本：v2.36.2。日期：2026-11-10。

准入请求携带完整快照，面板可能在判断准入结果前更新已保存的快照基线。此前节点只在周期同步成功后更新续期基线；准入被拒绝或确认丢失后，来源内容可能恢复原样，节点便继续按旧基线续期，收到 412 后才补发完整快照。

现在按准入代数和在途数量判断续期基线是否可靠。携带快照的准入开始后，旧基线不可继续复用；同步过程中若有准入在途或新准入开始，该次确认不作为后续续期的依据。稳定期完整同步成功后恢复轻量续期。网络等待不占同步锁，不串行阻塞其他来源申请。

准入超时或失败不代表面板没有保存快照，因此同样使基线失效。会话、序号、设备名额和许可期限校验保持原规则；出现真正的快照丢失时仍按同一序号补发完整快照，不主动关闭现有连接。

验证覆盖普通合并准入、许可缓存模式、拒绝、确认丢失、准入在途和迟到同步确认。需通过面板升级节点后生效；仅更新面板的日志分类不会修正旧节点的基线管理。
