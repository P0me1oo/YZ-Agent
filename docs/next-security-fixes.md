# Next 0.22.0 修复兼容

Agent 2.46.0 为本地开发版本，尚未发布或更新运行节点。核心依赖没有升级。

## 转发

撤销先执行再保存，保存失败不保持旧入口；每次新进程等待面板在线授权，不从旧缓存恢复转发。运行中的有效策略在短时断联时继续保持。内网、本机及元数据目标须在节点配置明确允许，格式和行为见[端口转发](port-forwarding.md)。

目标许可只由本机配置控制；多实例显式空列表清除继承，加密保存后不会从旧密文恢复被移除的许可。Realm也检查NAT占用，读取工具或权限不足时上报警告，明确冲突则拒绝。

## 用户快照分块

HTTP请求声明 `X-YZ-Snapshot-Chunks: 1`，WebSocket声明 `snapshot_chunks=1`。旧面板忽略声明后仍使用原协议。Next 0.22.0 对超过1MiB的快照返回分块描述。

512KiB原始块、128MiB用户总上限、120秒有效期。HTTP按认证身份下载指定编号和索引的块，各节点共用单下载槽；WebSocket每连接对全部未完成快照共享128MiB用户预算，控制字段另限4MiB。全部收齐后核验长度和SHA-256，再按原事件一次性应用；断线丢弃残片，拒绝错序、重复、混合版本、超时及摘要错误。

实际Next联调使用125125位授权用户，HTTP51块、约25MiB；HTTP和WebSocket完整用户编号集合及版本一致。超过32MiB的HTTP边界另由专项测试覆盖。

## 上报兼容

Next新版会记住已下发的用户／线路授权范围，拒绝范围外的新流量批次。Agent现有持久化批次编号与重试机制保持。首次升级前应先排空待报流量：旧面板未记录已经撤权的历史授权，部分从未入账的旧批次可能无法核验；不能用自报流量创建授权。

本次受影响包、完整竞态及静态检查结果见相邻 Next 工程的 `docs/security-fixes-20261125.md`。没有执行Commit、Push或部署。
