# 日志管理

## v2.36.1 错误日志补全

机器控制轮询、日志握手/落盘/上传、证书续期记录和临时限速状态失败增加脱敏诊断；中转流量、在线来源和连接快照采样失败按警告记录。同类重复故障最多每分钟一次，成功后再次失败立即记录。

日志上传器自身诊断只走本地出口，不重新进入上传队列；缓存损坏时保留原文件，等策略明确允许后报告。日志文件写入失败通过标准错误输出固定故障类型，不输出原记录。启动失败时最多用五秒确认日志策略，全部允许才打印原因；隐私保护和未知策略继续静默。上报格式、批次重试和核心依赖不变，运行中的节点需要另外升级。

故障注入与隐私、限频、回滚边界见[错误日志覆盖](../../YZboard/docs/error-logging.md)。Go 1.27.3 并发检测通过：日志、采集、机器控制、节点服务、启动入口和面板客户端执行全部测试，配置及双核心日志适配执行相关用例；核心相关测试使用正式构建标签。覆盖磁盘失败、上传超时、损坏缓存保全、策略静默与恢复、认证头脱敏和本地诊断不递归；完整发布验证结果见[兼容矩阵](../YZ_COMPATIBILITY.md)。

Agent `v2.26.0` 与面板 `1.107.1` 已发布，支持在面板按机器永久停用运行日志。停用后 Agent、节点、双核心的本地输出和运行日志上报全部停止；详见[运行日志设置](log-privacy.md)。下方保留日志采集设计说明。

Agent `v2.23.0` 为本地开发版本，配套面板 `1.103.0` 和管理端 `0.74.0`，尚未发布。完整页面、存储与回退规则见[面板日志管理](../../YZboard/docs/log-management.md)。

Agent 运行日志关联所属机器和节点，sing-box 原始日志关联核心实例；Xray 原始日志为进程共享，只在一个可信上报身份时采集。多个独立身份共享进程时不把全局日志复制到各面板，节点服务生命周期和启动故障仍保留节点归属。

每 5 秒独立发送最多 128 条，最多缓存 4,096 条及一个待确认批次。发送前落盘固定编号，面板确认后移除；本地队列在网络不可达时继续保存，恢复后重试。缓存仅保存隐藏认证内容后的文本，Linux 权限为 `0600`，目录位于当前配置目录。损坏文件保留并停用本次采集；队列满、存储失败与突然终止可能丢失记录。只采集新运行日志，不读取服务器历史文件。

带宽事件每秒检查共享限速器是否出现欠额，按本周期检测到欠额的秒数汇总，上限为 Mbps；不等于拒绝次数或精确等待时长。配置限速但没有真实欠额不记录，采样可能漏掉短暂等待。连接数、连接建立频率和设备数继续使用原事件；已组成上报批次的限制事件保存并在重启后以原编号重发，尚未组批的内存事件可能丢失。

新采集由面板握手声明 `agent_log.version=1`，旧面板继续原功能，不开启新日志上报；独立运行模式不采集。正式使用先更新面板后更新 Agent，两个核心依赖不变。
