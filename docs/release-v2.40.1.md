# Agent v2.40.1 发布

维护者：P0me1oo。日期：2026-11-17。

[v2.40.1](https://github.com/P0me1oo/YZ-Agent/releases/tag/v2.40.1) 已发布并设为 Latest，固定源码 `6d4f1dd6c156719e7f4f8a8cc22db08bda027099`，配套面板 v2.23.0。包含全部本地 v2.40.0 更新及本次发布检查发现的监听修复：健康检查不再发送 Reality 空握手，复用已成功的 HTTPS 地址；运行日志缓存按变化保存，加密日志复用句柄，并按面板声明的最低等级提前筛选上传日志。两个核心和锁定依赖保持不变。

完整检查发现 WireGuard 隔离网络空间创建可能结束主线程，该线程的连接表不代表正在运行的监听线程。Linux 读取期间固定当前线程，使用其网络空间及同一进程的描述符核对监听，再将归属规范为实际进程编号。新增独立回归在旧实现中稳定失败；修复后该项、前序 WireGuard 后的四个 Reality 场景及完整矩阵通过，见[机制与回归](healthcheck-logging.md)。v2.40.0 标签保留作为候选源码记录，本次创建的旧候选 Release 草稿已移除。

Go 1.27.3 / Linux amd64 / Zig 0.15.2 / 正式功能标签：最终固定源码 41 包完整竞态检查的 1073 个顶层用例通过；8 个固定依赖包的 43 项及 10 份安装器检查按相同来源、SDK 和环境复用。合计 **1116 个顶层用例通过**，6 个既有原生环境用例按条件跳过，没有失败或数据竞争。没有复用失败的测试包。健康检查及服务层静态检查通过，命令、环境和具体跳过见[完整核验](release-v2.40.1-tests.json)。

Linux amd64、arm64 的 Agent 与兼容管理程序在干净固定提交上构建；版本、完整提交、正式核心来源、架构及 `vcs.modified=false` 均逐项通过，旧兼容程序与对应 Agent 逐字节一致。13 份正式附件全部可匿名获取，大小、本机摘要与 GitHub 摘要一致，见[附件核验](release-v2.40.1-verification.json)。正式核心仍为 YZ-sing-box v1.16.0 / `ad0c0cfbc7c3827f3058aa666d9f1a3b0e0fd085` 和 YZ-Xray-core v26.12.0 / `36f4516090e3e2fe88dcbe0840126582cd6fb795`。

GitHub 自动检查在启动阶段失败，没有执行测试步骤，不计为通过；发布使用上述本机检查。没有发布 Docker 镜像或升级线上节点。需要更新节点时，在面板“服务器管理”选择单台或批量“升级”，再按操作结果及回报版本确认完成；固定回退版本为 v2.39.0。
