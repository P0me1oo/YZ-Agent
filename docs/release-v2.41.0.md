# YZ-Agent v2.41.0 发布

维护者：P0me1oo。日期：2026-11-19。

[v2.41.0](https://github.com/P0me1oo/YZ-Agent/releases/tag/v2.41.0) 已正式发布并设为 Latest，固定源码 `c9a7d18e4d3207197ef35ce16a817185cbd78326`，推荐配套面板 v2.24.1。本版包含节点审查复核后的全部修复，详见[逐项修复及兼容边界](audit-recheck-20261118.md)。

加固安装升级的版本与附件来源、面板通信、配置解密隔离、证书和 DNS 凭据、面板管理的直连目标及加密日志恢复；修正待报流量检查点、双核心路由和 Reality 回源、WireGuard 多对端路由、落地健康、用户热更新、自动限速、最后解绑、停机等待、防火墙重试及远程管理身份识别。

Go 1.27.3 / Linux amd64 / Zig 0.15.2，正式功能标签下 41 包完整竞态回归的 1081 个顶层用例通过，无失败或数据竞争。10 组安装脚本及语法检查通过。6 项既有原生防火墙、隔离来源或随机端口环境用例按条件跳过，未把这些用例计为通过；完整清单见[测试核验](release-v2.41.0-tests.json)。

Linux amd64 / arm64 的 Agent 与兼容管理程序均从上述干净固定源码构建，版本、完整 VCS revision、架构、`CGO_ENABLED=0` 及 `vcs.modified=false` 核对一致。历史 `xboard-node` 程序与对应 Agent 逐字节相同。13 份附件均已匿名下载，大小、本机 SHA-256、GitHub 摘要及校验清单全部一致，见[附件核验](release-v2.41.0-verification.json)。

实际核心保持 YZ-sing-box v1.16.0 / `ad0c0cfbc7c3827f3058aa666d9f1a3b0e0fd085` 与 YZ-Xray-core v26.12.0 / `36f4516090e3e2fe88dcbe0840126582cd6fb795`，没有使用相邻核心工作区替代正式依赖。sing-box 的旧地理规则需要改为规则集或显式域名、网段；需要 Reality 防盗用时选择 Xray；面板管理的直连出站访问内网时应改用节点本机配置。

GitHub 自动检查因账户账单锁定未启动，测试步骤数为 0；发布使用上述本机检查与固定源码构建，Docker 镜像任务跳过。本次只发布 Agent，没有升级运行节点。需要更新时，通过面板「服务器管理」选择单台或批量「升级」，按操作结果及节点回报 v2.41.0 确认完成；固定回退版本为 v2.40.1。
