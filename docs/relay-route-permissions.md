# 中转线路权限

配套版本为 Node `v2.3.1` 与面板 `1.37.1`，发布状态见 [兼容矩阵](../YZ_COMPATIBILITY.md)。此前入口只认证用户，未按用户限制落地线路，因此从订阅隐藏落地不等于撤销实际连接权限。

面板向入口下发自身与各落地授权用户的并集，并给每个用户附带可使用的线路编号数组（协议字段 `relay_routes`）。只拥有落地权限的用户可经入口访问对应线路，但不能使用入口直连。空数组拒绝全部线路；缺省数组保留旧面板兼容行为，因此只升级 Node 或只升级面板都不能完成此次修复。

Xray 在 Node 包装的调度器内检查用户与会话线路编号，撤权时取消对应连接任务并关闭连接。sing-box 只生成获准线路的认证身份与路由，热更新时保留过渡规则，随后撤销旧身份及其 TCP/UDP 连接。两者均在同一把锁下检查权限并登记连接，避免连接在撤权过程中漏过登记。

用户快照和内核摘要包含线路权限，数组复制保留空值与缺省的区别。权限变化会触发内核更新；重复更新和迟到快照不重新放开线路。旧实例排空期间也应用最新权限。其他线路保持授权，恢复权限后可重新连接。

本次修改仅位于 Node 适配层，固定依赖保持 sing-box `v1.14.0-yz.2` 与 Xray `v0.0.0-20260930033643-7c5728ec7d0f`，两个核心 fork 无需发布新版本。管理端沿用 `0.18.0`。发布后先更新 Node、再更新面板，必须两端完成后验证撤权；回滚任一端可能恢复旧行为。

本地回环测试使用随机测试凭据并由测试框架清理临时目录。真实核心覆盖 Xray、sing-box 的 VLESS/HY2，验证旧配置、会话复用、现有 TCP/UDP、保留线路、空权限、恢复和重启；模型、服务及并发测试验证复制、摘要和旧快照保护。最终结果见 [兼容矩阵](../YZ_COMPATIBILITY.md)。未操作生产服务器。
