# Vision 流量计量

维护者：P0me1oo。Agent 版本：`v2.30.1`，固定源码 `d553bc5d5d3ab57b5a622c898fe15ae466e89116`。核心源码：YZ-Xray-core `v26.11.1`，固定提交 `3c480b0c0d736157547f80036c0eb4687d3f1586`。

## 问题与实现

旧核心的快速复制只在结束后补计最外层 `SizeStatWriter`，遗漏限速包装后的用户计数及中转内层计数，并绕过限速；单层计数也会让长连接实时用量等待复制结束才更新。

新实现保留内核快速复制。Linux/Android 以两次 `splice` 经内核管道搬运每段数据：读入后按实际大小执行全部限速回调，再写入目标并及时更新全部嵌套计数回调。等待期间数据留在内核管道，不拷贝到程序缓冲区；大小不超过 64 KiB 及当前限速器的突发额度，小尾段按实际字节扣减。

`common/buf` 提供可选包装回调和解包接口，现有包装保留普通写入行为。Agent 的关闭登记提供 `UnwrapWriter`，核心可遍历其后包装，关闭仍由原生命周期回收。没有改变面板协议、认证或中转身份，也没有禁用已认证用户的 splice；前一版全量回退已撤掉。

取消中断套接字轮询及限速等待，错误只计已写出前缀；单方向 EOF 保留反向传输。不支持内核或来源时，仅在尚未消耗数据的情况下回退普通复制。删除条件见核心[版本说明](../../YZ-Xray-core/YZ_FORK.md)。历史遗漏流量不在本次修复中追回。
