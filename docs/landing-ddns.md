# 落地 DDNS

配套 YZboard 2.29.0 和 Dash 0.111.0，前置 Agent 最低 v2.50.0。面板保留落地域名并附带 DNS 服务已确认的 IP；Agent 校验 IP 后用于中转实际连接。旧面板不带确认 IP 时继续使用原连接地址。

两个内核均覆盖 Shadowsocks、VLESS 和 WireGuard，保留 TLS / Reality 握手域名、凭据、端口和线路编号。IP 变化参与配置摘要并重建核心配置，因此现有连接可能中断后重连；重复配置不因该字段反复重建。测速、来源核对也由面板下发相同确认地址。

本次发布使用独立分支 `release/v2.50.0`，基于 v2.48.0 固定提交 300453fe3dceeb0253f61202ef979e60159c06bc。主工作区的 v2.49.0 正在开发，未纳入此工作树，也未被本次修改覆盖。版本 v2.50.0 从该固定来源构建；发布结果另见发布记录，运行节点未升级。

完整使用、失效处理和回退见面板 docs/node-ddns.md。关闭该功能会恢复管理员填写的连接地址；回退 Agent 前应先在面板关闭落地 DDNS。
