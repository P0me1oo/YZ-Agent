# 安装过程说明

适用版本：`v2.37.3`。安装器和程序内嵌的升级脚本共用这些提示；已安装的旧程序及正式 Release 中的旧安装器，需要取得包含本次改动的新版本后才会显示新的格式。

参考 [Lite-agent 安装脚本](https://github.com/nuomiiiii/Lite-agent/blob/main/install.sh) 的标题、配置摘要和阶段提示，保留 YZ-Agent 的版本固定、安装包校验、镜像回退、systemd / OpenRC 服务管理和失败恢复。

## 显示格式

安装或升级开始时显示操作、系统、服务、数据目录、程序目录和目标版本。安装额外显示部署模式和核心选择；认证令牌仅显示 `***`，面板地址不进入摘要，避免带认证信息的地址进入日志。

执行过程使用 `[步骤]`、`[信息]`、`[警告]`、`[错误]` 和 `[配置]` 中文标签。服务运行并通过启用的健康检查后，才显示完成摘要；例如：

```text
===========================================
    YZ-Agent 安装完成
===========================================
[配置] 版本：v2.37.3
[配置] 服务：yz-agent（systemd，已运行）
[配置] 程序：/usr/local/bin/yz-agent
[配置] 配置：/etc/yz-agent/config.yml
[配置] 健康检查：http://127.0.0.1:65530/healthz（已通过）
[配置] 管理命令：/usr/local/bin/yz-agent
```

版本来自准备安装的程序本身，路径使用本次安装或迁移的实际结果。禁用健康检查时，摘要明确显示“已禁用，仅确认服务运行”。失败时保留中文错误、恢复结果及需要保留的恢复文件位置。

终端保留颜色，管道或文件输出自动使用纯文本；设置 `NO_COLOR` 或终端类型为 `dumb` 时也禁用颜色。提示中的路径和文本按字面输出，不解释反斜杠转义。

脚本自身的帮助、状态和错误提示使用中文。包管理器、下载工具、服务管理器及节点程序的原始输出沿用各工具的语言，不替换原始诊断。

## 依赖与参数检查

安装前检查 `curl`、可用的 CA 证书包，以及文件校验和迁移所需的工具。仅缺少对应能力时安装 `curl`、`ca-certificates` 或 `coreutils`，不再额外安装未使用的 `wget`；OpenRC 在服务识别阶段已经要求可用，不额外安装。

检测文件工具时核对 `mv --version`，避免把不支持迁移参数的 BusyBox `mv` 当作完整的 GNU coreutils。依赖齐全时跳过包管理器；安装命令失败、安装后仍缺少依赖，或未知系统缺少依赖时停止，保留原始错误用于排查。未知系统已有完整依赖时可以继续。卸载不执行依赖安装，已是最新版或高于最新正式版的升级仍不下载、不安装依赖、不重启。

已有命令和参数保持使用方式。缺少参数值、误拼参数和缺少必填安装信息，会在创建安装锁或调用包管理器之前报错；安装目标和历史版本迁移仍由原来的配置处理和恢复流程负责。

## 验证

新增的输出与参数检查覆盖摘要脱敏、纯文本、字面输出、缺失参数、未知参数和卸载跳过依赖。依赖测试模拟命令缺失、BusyBox、各类包管理器、安装失败和安装后复查，不修改系统软件。

安装器回归还覆盖新装、自定义目录、历史命名迁移、凭据传递、健康检查、版本比较、镜像选择，以及替换失败和中断后的恢复。
