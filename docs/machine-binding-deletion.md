# 已删除服务器的自动解绑

Agent v2.37.0 与面板 2.14.0 配套，已正式发布，尚未部署。发布来源和完整验证见[发布记录](release-2.37.0.md)。

在面板删除服务器后，Agent 启动时、安装合并旧配置时和运行期间每 30 秒核实一次绑定状态。面板明确确认该编号已经删除后，移除本机对应的机器绑定；重新安装其他服务器编号时不再带入已确认删除的旧身份。安装阶段先在暂存配置中清理，现有安装回滚流程继续负责正式切换。

自动解绑清除配置中的对应实例、没有被其他实例引用的凭据变量和安装摘要。运行中通过已有配置重载路径应用，其他绑定仍保留，但共享进程中的节点会经过一次正常排空和重载。证书、待补报流量、内核数据目录及历史备份保留。

最后一个绑定移除后，Agent 保持等待绑定，不反复退出；已配置的健康端口返回 HTTP 503，状态为 `unbound`，不会把无绑定误报为业务正常。新增有效绑定后恢复。未提交完成的凭据和安装摘要清理通过本机完成记录重试，该记录不保存令牌。

## 删除确认与兼容

Agent 通过 HTTPS（本机测试允许回环 HTTP）向 `/api/v2/server/machine/binding-status` 发送服务器编号、原凭据和每次新生成的随机挑战。面板返回版本 1、匹配的编号、`deleted` 状态、原挑战和 HMAC-SHA256 确认；Agent 全部验证成功才清理。不会跟随重定向，单次请求最多 5 秒，启动和安装预检整轮最多 10 秒；运行中逐个检查，避免前面的离线面板使后续绑定一直得不到检查。暂时未能核实的绑定保留并在后续轮次重试。

面板将删除凭据与实际删除放在同一数据库事务，仅保留令牌的 SHA-256 摘要，不保留明文令牌。删除凭据持久保存，使离线 Agent 日后可以补清理。协议确认内容为 `yz-agent-machine-deleted-v1\n<编号>\n<挑战>`，HMAC 密钥为原令牌的二进制 SHA-256 摘要。

下列情况不会自动移除：禁用、令牌重置或错误、普通 401/403/404/410/5xx、网络故障、无效或重放响应、旧面板、公开 HTTP 面板，以及面板升级前已删除且没有保存删除凭据的服务器。旧版整文件加密恢复副本无法可靠识别所有内部实例，也不直接自动清理；日常按实例保护的配置支持在旧密钥已不可用时解绑。

本次故障中的 117 已在旧版面板删除，没有可核实的删除凭据，仍需手动清理一次。不能根据“服务器不存在或已禁用”的合并错误自动判断已删除。

## 验证

新增测试覆盖删除确认、身份与挑战不匹配、重放、重定向、禁用和旧接口；配置覆盖多实例、共享凭据、加密实例、并发重绑、断点恢复和最后一个绑定。安装合并分别验证 sing-box/Xray 默认内核。进程测试使用回环模拟面板、临时身份和目录，验证启动清理、等待绑定、重新绑定及运行中清理。

Go 1.27.3 / Linux amd64，正式功能标签下九个受影响包的竞态回归通过；安装器健康、隐私、默认内核、目录和名称迁移/回滚测试通过。面板 PHP 8.4.27、SQLite 和 MariaDB 11.8.6 严格模式各 51 项、572 条断言通过。amd64 开发构建通过，核心依赖保持原固定版本。上述为前期开发验证；正式发布追加的完整回归见发布记录。本次未更新生产。

源码摘要、构建来源和验证结果见[开发核验记录](machine-binding-deletion-verification.json)。
