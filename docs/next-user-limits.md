# YZboard Next 用户限制兼容

YZboard Next 0.18.0 沿用 Agent 的带宽、连接准入、自动临时限速和设备许可协议。跨节点共享 IP 名额需要服务器握手成功及每节点设备协调会话成功建立；从未启用协调的旧面板升级后，已有 Agent 需要重启以启动许可管理器。

机器模式节点初始化必须先成功握手，再获取并应用配置与用户名单。握手暂时失败时等待初始化重试，不使用尚未确认的协调能力启动节点；恢复后建立共享许可会话。这修复了旧设备会话仍存于面板、但新进程首次握手失败时退回本地 IP 限制的窗口。

配套修改已按用户授权部署至 Huawei-SG、YT-HK 的独立 `yznext-agent` 测试服务，未创建正式发布或更新其他实例。验证覆盖握手失败时不请求用户名单，以及恢复后成功加载用户并启用协调能力。Next 侧同一用户的同一 IP 在多个节点共用名额，IPv6 按 /64 计数；满额拒绝新的来源，持有许可仍按明确归还或固定期限释放。
