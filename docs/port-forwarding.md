# 服务器级端口转发

YZ-Agent 2.46.0 支持 YZboard Next 的 Realm 和 nftables 转发。机器模式独立轮询 `/api/v2/server/machine/forwarding`，不要求中转服务器先创建代理节点。按节点的传输协议启用 TCP、UDP 或两者；代理核心与用户计费保持在目标节点。

运行时需在 PATH 中提供 `realm` 或 `nft`；不会自动安装软件。nftables 需 CAP_NET_ADMIN、系统相应地址族 IP 转发和防火墙转发放行。Agent 不改系统拥塞算法、IP 转发 sysctl 或已有防火墙策略。

配置、独占锁及 nftables 归属记录放在配置目录中的 `forwarding-<身份摘要>/`。成功取得并验证的期望配置原子写入，重复配置不写盘、不重启 Realm。每个 Realm 进程限制一个 Tokio 工作线程，退出后下一轮检查恢复；Agent 退出时回收进程，异常退出通过父进程死亡信号避免残留。运行中面板暂时不可达时保持本进程已经确认的策略。撤销先执行再尝试落盘；保存失败不会恢复旧入口。每次进程启动清理自身残留 NAT，等待面板在线重新授权，不从诊断缓存恢复运行。

nftables 使用专用 inet 表及所有者注释，事务修改、按归属删除。DNS 解析结果在应用前检查本机循环和其他转发入口；实际目标使用已验证 IP。检查 TCP／UDP 端口和其他 NAT 规则，无法确定 NAT 端口表达式时拒绝覆盖。停用或更新会仅删除本功能旧映射对应的连接记录。

机器控制请求只读上报系统默认 TCP 拥塞算法，失败传空值；不受负载采样开关影响。

使用与测试环境结果见相邻 Next 项目的 `docs/port-forwarding.md` 和 `docs/port-forwarding-acceptance.md`。普通四层转发不携带真实客户端来源 IP，来源限制使用目标实际看到的中转 IP。

## 本机目标授权

默认只允许公网目标。回环、私网、本机接口、链路本地／云元数据及保留地址必须在本机允许，面板下发不能授予例外：

```yaml
forwarding:
  allowed_targets:
    - cidr: 127.0.0.1/32
      ports: [38141, 38142, 38143]
    - cidr: 10.20.0.0/16
      ports: [443]
```

每项须填写规范网段及明确端口，最多256项、每项最多256端口。多实例显式空列表会清除继承许可；加密保存及重载也保留本机清除结果。升级前须为已有内网转发补充此配置。允许目标仍不能绕过转发循环检查。

DNS 每15秒刷新；仅完全不变策略的临时错误允许保留上次核验IP，最长自成功核验起60秒。域名不存在、目标不安全或循环时立即拒绝。NAT 漂移检查30秒，策略改变立即核验。Realm缺少读取NAT的工具或权限时允许运行但上报警告，明确冲突则拒绝；nftables仍要求完整权限。
