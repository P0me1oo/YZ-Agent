# Reality 目标检测

`v2.14.0` 配套面板 `1.88.0`、管理端 `0.60.0`，增加 CDN 厂商及页面状态，目前尚未发布。任务可选 `diagnostics: true` 时，在证书检测后并行查询 CNAME 与读取 HTTP 状态，最多 3 秒且不超过单目标原有时限。报告的可选 `cdn` 包含状态、厂商列表和不含响应头值的证据；`http` 包含检查状态及实际收到的状态码。

HTTP 请求仅在证书有效时执行，复用已校验 IP 的 TLS 连接，支持 HTTP/2、HTTP/1.1 和自定义端口；请求 `GET /`，不使用环境代理、不跟随跳转、不读取正文，响应头上限 32 KiB。IP + SNI 检测不使用 SNI 的另一个解析结果推测当前 IP 的 CDN。CDN 使用域名标签边界匹配与厂商特有响应头，不以通用缓存头、NS 或证书机构判定；HTTP 403、404、5xx、超时不覆盖原握手结果或延迟。

未携带增强开关的旧格式任务不执行额外请求，报告继续省略新增字段。位置查询由面板使用内置 ip2region 本地 IPv4 库完成，Node 不请求位置 API、不增加数据库或下载依赖。没有被墙检测。两个核心及其固定依赖不变。

Node `v2.12.0` 配套面板 `1.85.0`、管理端 `0.57.0`，已正式发布；先更新面板，再更新 Node。完整交互和限制见 [面板使用说明](../../YZboard/docs/reality-target-scan.md)。本功能在服务器模式启用，不修改 Xray、sing-box 或代理配置，不开放新监听端口。

Node 在原五秒控制请求中声明 `reality_scan_supported`，附带最近一次 `reality_scan` 报告，并接收响应中的同名任务。报告独立于重启/升级的 `operation`，服务器不需要开放入站管理端口。旧面板忽略新增字段后继续工作；旧 Node 未声明能力时，面板拒绝创建检测任务。

检测任务包含任务标识、目标列表、可选单目标 SNI 和过期时间。后台最多 32 并发检测公网目标，单个网段最多 256 个地址，总计最多 512 个；域名握手 10 秒、IP 初步发现 4 秒，扫描总时限 170 秒。解析结果全部校验并固定拨号 IP，拒绝私网、回环、链路本地、共享及保留地址。默认候选与面板一致，删除 Cloudflare，仅管理员主动输入时才检测它。

域名检测验证 TLS 1.3、HTTP/2、X25519 或 X25519MLKEM768，以及系统信任的证书链和主机名。IP/网段先读取未指定 SNI 时的证书域名，再按域名重新解析和握手；返回的延迟与 IP 对应复测连接，不能视为网段全部 SNI 的清单。延迟计算到 TLS 握手结束，包括解析与 TCP 连接，不含后续证书校验。

运行状态及结果只在内存中保存，重复任务返回已有结果而不重复扫描；新任务替换时取消旧任务，进程退出随上下文取消。面板按机器、任务和进程匹配结果，超时或重启后需重新发起。测试不连接公网：使用注入的解析及拨号替身，将已检查的公网地址映射到本机 TLS 服务。
