# Next 用户实时采样

Agent v2.55.0 通过节点状态回执与 Next 0.34.0 协商用户明细。节点能力、观看名单和租约仅作用于当前节点。兼容旧面板的完整统计路径保留；新面板连接旧 Agent 时，缺少的用户指标显示未知。[面板使用说明](../../YZboard-Next/YZboard-Next/docs/user-usage.md)

- 采样循环一次读取用户及中转累计账本、在线人数和总连接数。Xray 合并正在排空的分发器，sing-box 使用当前用户的活跃连接计数。按名单提取连接的实际公网来源并去重。普通 WireGuard 节点复用自己的连接与来源跟踪。
- 面板请求和实际启用自动限速的用户共享速度基线。使用相邻样本的原始上下行字节及实际时间计算 B/s。无订阅且无自动限速规则时释放展示基线。用户首次加入采样、计数回退及长时间间断时，缺测的速度保留为空。
- 配置更新时重建限速规则索引。已有状态发送仍在途时，采样、配置同步和可靠流量结算继续运行。每个节点最多有一份在途状态上报，下一次可发送时构建最新的用户明细。
- 现有设备准入、每用户及中转计费账本独立运行。观看名单和详情批次不参与倍率结算，展示 IP 与设备名额分别使用完整 IPv6 地址和 `/64` 网段。

冻结的优化前工作树包含当时尚未提交的机器监控等功能。可在当前 Agent 的独立源码副本中应用[基线差异](benchmarks/user-usage-before.patch.gz)，得到本次对比使用的优化前实现。两份源码共用相同的计量夹具。[实测与复测命令](../../YZboard-Next/YZboard-Next/docs/user-usage-performance.md)
