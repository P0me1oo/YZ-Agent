维护者：P0me1oo。日期：2026-11-17。

本版汇总未发布的健康检查地址回退、隐私日志加密和代理访问记录开关联动。健康检查尝试已校验的 IPv4、IPv6 地址；隐私模式继续记录并逐条加密本地日志；访问记录核对停用代次，避免重新开启后补报旧缓存。配套面板 2.22.2；两个核心及其他锁定依赖保持原版本。
