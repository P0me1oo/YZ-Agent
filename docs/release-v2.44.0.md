# YZ-Agent v2.44.0 发布

维护者：P0me1oo。日期：2026-11-23。

[v2.44.0](https://github.com/P0me1oo/YZ-Agent/releases/tag/v2.44.0) 已发布并设为 Latest，固定源码 `b9d1602e532bb11a6f8cd98ae187fe59500e92cb`。配套面板 2.25.0 / Dash 0.107.0，共享分类、拦截顺序、已有出口及回退边界见[服务端路由](server-route-presets.md)。本版包含未单独发布的 v2.43.0 改动；正式核心依赖保持 YZ-sing-box v1.16.0 与 YZ-Xray-core v26.12.0。

Go 1.27.3 / Linux amd64 / GCC 14.2，正式功能标签下执行 42 个测试包完整竞态回归。首轮仅旧中转日志契约失败，1106 个顶层测试通过；将该测试更新为“入口直出、入口先拦中转、仅落地命中”三种情况后，两项日志专项通过，合计 1107 个不同顶层测试有通过结果。测试修改不改变产品源码，其余成功结果复用。6 项既有原生防火墙、来源隔离或端口选择用例按环境跳过。另有 8 个固定依赖包的 43 项、2 项独立 Mihomo 客户端检查、10 组安装脚本及语法检查通过，未报告数据竞争。见[核验记录](release-v2.44.0-tests.json)。GitHub [最终来源主测试](https://github.com/P0me1oo/YZ-Agent/actions/runs/45156153592) 已一次通过，覆盖完整竞态、固定依赖、Mihomo 和安装检查；原生防火墙矩阵另在收尾，完成情况以工作流为准。

Linux amd64 / arm64 的 Agent、兼容程序和管理程序由固定干净源码构建，核对版本、提交、架构、`CGO_ENABLED=0`、`vcs.modified=false` 和真实模块来源。13 份附件下载、大小、本机 SHA-256 和 GitHub 摘要全部匹配，公开元数据可匿名获取，见[附件核验](release-v2.44.0-verification.json)。

此次未升级运行节点、未发布 Docker 镜像。需要新分类和入口拦截顺序的节点，可通过面板“服务器管理”升级并核对回报版本。固定回退版为 v2.42.0，回退前移除 sing-box 分类引用并确认旧版的中转优先级。相邻核心工作区的 HTTPUpgrade 修复仍不包含在正式依赖中。
