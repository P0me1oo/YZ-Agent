# 节点运行检查与套餐临时限速

维护者：P0me1oo。配套版本：YZboard 2.6.1、管理端 0.91.1、YZ-Agent 2.33.1。已发布，尚未部署；来源与验证边界见[发布记录](../../YZboard/docs/release-2.6.1.md)。

## 配置应用

Xray 对仅改变路由规则、且入站、出站、TLS、用户和静态路由字段均不变的配置执行热更新；相同配置不重复重建。自定义配置文件、监听、出站或 TLS 变化保留原重建流程。更新失败仍按现有策略停止本节点，不恢复已撤销的旧权限。sing-box 原有纯路由和双核心用户热更新继续使用。

面板读取实际运行状态，只对失败显示提示，成功不弹提示。失败信息经过脱敏，完整排错仍查看节点日志。健康检查设置及续期请求不触发核心重建；证书续期后真正更换材料时仍应用新证书。

## 链路检查

管理员在节点“链路健康”的详情中启用，默认关闭。目标仅接受无认证、无查询参数的公网 HTTPS 地址；Agent 核对所有解析地址，固定已经核对的 IP 建连，验证目标域名证书，不跟随重定向。间隔 30–3600 秒。

探测源为节点本机：检查 TCP 监听，并通过运行中的核心默认出站及中转出站请求目标；内部中转因此经过真实代理握手。UDP 监听（包括 XHTTP HTTP/3）不通过 TCP 判断，界面明确说明未检查。它不是用户所在地延迟，也不验证外部入口认证、CDN、公网可达性或完整客户端订阅。

检查独立于主循环，最多持续 30 秒，同时只运行一轮。每轮至多检查默认出站及 16 个中转出站，最多四路并发；整轮超时后的未完成项显示未知，实际连接失败才标为故障；超出时显示部分检查，不显示全量健康。重载前的迟到结果按配置指纹丢弃。只进行诊断，不触发自动重启或调整调度池。

探测不使用面板用户，不计入套餐扣费或在线设备；网卡仍会产生少量真实检查流量。健康历史保留 24 小时，可用率是已采集样本中成功比例，不把断联期间当作成功。Agent 旧版本、状态过期或功能未开启分别展示。核心停止时清除当前健康结果，恢复后重新检查；实时通道只上报一份运行状态，旧报告方式继续兼容。

## 证书

上报域名、签发者、有效期、SHA-256 指纹、续期结果及运行核心是否加载当前材料，不上传证书私钥或 DNS 凭据。ACME 续期沿用原证书管理器；后台失败时保留原证书。管理员可以发起一次强制续期，节点以请求编号落盘去重，重启不重复执行旧请求；中断请求显示失败，需重新提交。面板五分钟内限制重复续期请求。

## 自动临时限速

规则在套餐中设置，购买、续费、管理员设置套餐和勾选“同步更新已有用户”时写入用户规则快照。未勾选同步时已有用户继续原规则；旧面板不下发规则时保持原限速。

Agent 按新采样时间判定，持续模式处理每个低速样本，窗口每秒最多计数一次；用户同步不重用旧速度，规则摘要只在规则变化时计算。按用户在本节点的真实上传、下载或两者较大值判断；不合并跨节点速度。支持持续超阈若干秒或窗口内达到若干个超阈秒数，采样中断会重置判定窗口。

触发后取临时上限与用户正常上限的较小值，原地更新限速器，使已建立的连接也生效；不关闭连接、不修改计费倍率。到期恢复当时的正常限速，规则变化或删除用户会解除旧临时状态。正在执行的处罚写入实例目录，权限 0600，沿用隐私加密；重启按原到期时间恢复，不延长处罚。文件损坏保留原文件并报告错误，内存判定继续，无法恢复的旧处罚不能保证继续执行。

用户列表下载速度列显示当前临时上限，详情包含对应节点及结束时间。实时状态过期后不继续显示旧处罚。
