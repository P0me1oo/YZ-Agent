# 来源 IP 黑白名单

Agent `v2.20.0` 配套面板 `1.99.0`、管理端 `0.70.0`，发布核验状态见兼容矩阵。使用方式见[面板说明](../../YZboard/docs/source-policy.md)，验证结果见[兼容矩阵](../YZ_COMPATIBILITY.md)。

## 配置与兼容

面板按节点下发来源策略（协议字段 `source_policy`）：

| 配置 | 字段 | 含义 |
| --- | --- | --- |
| 限制模式 | `mode` | `disabled` 关闭、`blacklist` 黑名单、`whitelist` 白名单 |
| 大陆屏蔽 | `block_cn` | 仅黑名单或旧大陆策略参与匹配 |
| 允许来源 | `allow_ips` | 白名单的允许地址，或大陆屏蔽的具体例外 |
| 屏蔽来源 | `block_ips` | 黑名单的具体屏蔽地址 |

模式缺失时保留历史行为：大陆屏蔽开启才启用策略。明确关闭优先于保留的大陆开关及名单。白名单至少填写一个地址，每份名单至多 128 个具体 IPv4/IPv6，不接受域名、网段、带区域的 IPv6、未指定地址、组播地址或等价重复地址。

白名单从全部 IPv4/IPv6 地址中扣除允许地址，生成统一的拦截集合，不受保留的大陆开关或具体黑名单影响。黑名单先从大陆集合中扣除允许例外，再加入具体黑名单，因此具体黑名单优先于地区例外。手动名单不读取、下载或刷新大陆库。

Node 深拷贝名单进入配置快照，原始策略参与配置去重，编译后的集合另参与核心重载判断。模式、名单或有效地区集合变化沿用现有重载流程，不保证已有连接立即关闭。

## 执行范围

Xray 和 sing-box 使用相同集合。Xray 使用独立丢弃出口，sing-box 使用拒绝动作，规则优先于自定义路由，不能被自定义同名出口绕过。只匹配实际代理入口，保留 REALITY 伪装回源；通过来源检查的连接仍需通过认证、权限和后续路由。

普通 WG 在外层 UDP 接收和发送处匹配同一集合；WG 中转落地拒绝单独启用来源限制，应在前置入口设置。普通代理入口和非 WG 落地分别执行本节点策略，不自动识别或放行前置出口。接收 PROXY 协议时沿用既有来源传递，不改变该协议的信任范围。

## 大陆库缓存与故障处理

仅启用大陆屏蔽时使用 `https://raw.githubusercontent.com/Loyalsoldier/geoip/release/text/cn.txt`，两种核心共用。有效数据保存为地理数据目录中的 `cn-source.txt`，同目录共用下载锁与不可变内存快照。

每 24 小时刷新，失败 5 分钟退避，运行循环每分钟检查。HTTPS 下载限制 20 秒、4 MiB，数据须同时包含 IPv4 和 IPv6，不接受空库、错误页面、无效条目或全地址网段。先校验并写入临时文件，再替换有效缓存；顺序、空白或重复条目变化不产生新版本。

更新失败保留旧数据；首次没有有效库时停止该节点，后台取得数据后恢复，不降级为无限制运行。重启复用有效缓存。切到手动名单后，迟到的地区下载结果不触发该节点重载。

## 验证与回退

测试只使用保留地址和本机回环来源。专项验证结果记录在兼容矩阵，不将本地模拟接口等同于真实服务器联调。核心 fork 和固定依赖保持不变。

部署需先升级配套 Agent，再启用新名单模式；旧 Agent 会忽略新字段。回退旧 Agent 前先在面板关闭来源限制并确认配置更新。
