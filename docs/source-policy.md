# 大陆来源拦截

`v2.7.0` 配套面板 `1.53.0` 和管理端 `0.30.0`，包含此前未发布的来源策略，并接入普通 WG。当前未发布，核心 fork 与固定依赖版本保持不变。

## 配置与执行

面板按节点下发来源策略（协议字段 `source_policy`），包含大陆拦截开关（`block_cn`）和最多 128 个具体例外地址（`allow_ips`）。缺失或关闭表示不使用本策略。普通 WG 在外层 UDP 接收和发送处使用同一网段库；WG 中转落地仍拒绝单独开启，用户来源在前置限制。

普通代理入口和非 WG 中转落地分别执行本节点的策略。入口开启后作用于经它认证的直出及中转请求；落地按自己看到的来源判断，通常是前置出口。例外不改变后续路由或权限，不自动识别前置出口，不复用已移除的防火墙白名单。

网段来源为 `https://raw.githubusercontent.com/Loyalsoldier/geoip/release/text/cn.txt`，Xray 与 sing-box 使用同一集合。读取、校验、下载和扣除例外在 Node 中完成；核心只执行生成的来源网段规则。Xray 使用独立丢弃出口，sing-box 使用拒绝动作，不允许自定义同名出口或优先路由覆盖本策略。只匹配实际代理入站，保留 REALITY 伪装回源路径。

## 缓存与故障处理

有效数据库保存为地理数据目录中的 `cn-source.txt`。同目录共用下载锁及不可变内存快照。每 24 小时刷新；失败 5 分钟退避，运行循环每分钟检查。HTTPS 下载限制 20 秒、4 MiB，数据必须同时有 IPv4 和 IPv6，不接受空库、错误页面、无效条目或全地址网段。

先校验并写入临时文件，再替换有效缓存。顺序、空白和重复条目变化不产生新版本。更新失败保留旧数据；首次没有可用数据则停止该节点运行，后台取得数据后恢复，不降级为无拦截运行。Node 重启复用有效缓存。

配置快照与编译后的网段分开，前者用于面板消息去重，后者参与核心重载判断。例外、开关或有效网段变化沿用现有重载流程；不保证已有连接立即关闭。非大陆地址被误收或大陆地址漏收时，结果受上游网段库准确性影响。

## 验证和版本

测试使用文档保留网段和本机回环来源，不使用生产用户、凭据或服务器。实际验证结果记录在 `YZ_COMPATIBILITY.md`。旧 Node 不认识新字段；部署时须先升级 Node，再开启面板策略。回退旧 Node 前先关闭此开关。
