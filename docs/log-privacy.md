# 隐私保护模式与独立面板入口

Agent [v2.28.1](https://github.com/P0me1oo/YZ-Agent/releases/tag/v2.28.1) 已发布，要求配套面板 `1.111.1`、管理端 `0.81.0`，一并交付 `v2.27.0` 开发阶段的本地文件加密。“隐私保护模式”保留永久停用日志，由面板提供文件密钥。已有设置继续沿用，不需要重建机器。

Agent [v2.26.0](https://github.com/P0me1oo/YZ-Agent/releases/tag/v2.26.0) 已发布，配套面板 `1.107.1`、管理端 `0.78.0`。

在面板“服务器管理”中提前开启“隐私保护模式”并保存，再安装配套 Agent。停用后 Agent、节点及 Xray / sing-box 的运行日志全部停止本地输出和上报；面板和 Agent 本地都没有重新开启入口。此设置不能通过调整本地日志级别恢复。

Agent 在取得明确策略前保持静默，已停用策略在配置重载和重启后继续生效；同进程任一身份停用，就关闭共享的运行日志出口。未支持策略的旧面板会让新 Agent 继续静默。完整范围、历史记录、回滚限制及服务器管理员权限边界见[面板运行日志设置](../../YZboard/docs/agent-log-policy.md)。

## 本地文件加密与自动恢复

开启后，Agent 通过原有机器或节点身份向面板领取该机器的文件密钥，使用 AES-256-GCM 加密程序管理的数据。密钥仅放在进程内存中，不保存到节点磁盘；这不是 SSH 公钥登录，也不需要手工在节点填写私钥。配置中的面板入口、身份、凭据引用，以及启动、健康检查和防火墙所需信息保留可读，服务重启后凭这些信息自动领取密钥。

保护范围包括每个实例的敏感配置、程序管理目录内的证书与证书私钥、ACME 状态、待确认流量、访问记录和历史运行日志队列、机器流量累计状态，以及位于该实例内核目录内的自定义配置。安装摘要仅保留必要的版本和实例信息，不再重复保存面板入口。由用户单独指定、放在这些目录外的共享证书或配置文件不会被自动改写。

Agent `v2.28.1` 中，Xray 和 sing-box 的自定义配置在启动及重载校验时也通过解密读取，支持 JSON 和 YAML。加密豁免仅限已登记的主配置路径及其同目录的 `credentials.env`、`install-meta.json`；内核目录中的 `config.yml` 或其他同名受管理文件不会因文件名相同而跳过加密。

已存在的受管理文件会原地迁移，保留原有数据；重复迁移不会重新累计流量或改变重试编号。各实例分别加密，一个面板暂时不可用时其他实例仍可恢复。正在运行的实例可继续使用内存中的密钥，冷启动则需要面板可达；暂时失败会保留文件并自动重试，不回退到明文运行。相同进程中不同机器不能使用重叠的数据目录，也不要为不同隐私策略的实例共用敏感默认值。

密钥领取要求 HTTPS 面板入口，本机回环测试地址除外。面板必须先升级到配套版本：旧面板已开启隐私保护、但不支持文件密钥时，Agent 停止受影响实例并等待恢复；未开启模式的旧面板继续沿用旧行为。

启动凭据 `credentials.env` 仍需供服务管理器读取，使用 `0600` 权限。复制单独的加密文件不包含密钥；取得完整节点目录及有效认证凭据的人仍可能向面板领取密钥。普通 LXC 的宿主机管理员也可检查进程内存，本功能不保证对宿主机保密。

### 面板备份与维护

面板按机器编号和自己的应用主密钥派生文件密钥，不把应用主密钥交给 Agent。恢复面板必须保留原数据库身份和 `APP_KEY`；轮换应用主密钥时，在 `APP_PREVIOUS_KEYS` 中保留仍有数据使用的旧密钥，待节点及所需备份迁移完成后再移除。丢失必要的历史密钥会使对应文件无法解密。普通令牌轮换不改变文件密钥，但节点仍需有效的启动凭据。不要删除、重建机器来代替编辑。

绑定增删、升级和配置目录迁移继续使用现有维护入口。安装备份中能够确认属于当前身份且具有可恢复认证信息的配置也会加密；无法确认或缺少恢复条件的历史备份保留原样，需要用户另行保管。

显式选择不支持加密的历史版本时，新程序先生成兼容配置，并在停止服务后恢复旧程序需要的数据；失败回滚也先转换恢复快照。无法取得必要密钥时，停止降级，保留当前程序、数据及恢复文件，并尝试重新启动当前服务。历史版本没有这项加密能力，也不能保证继续执行永久停用日志策略。

## 敏感文件权限

配置、凭据及安装记录在保存时使用仅所属用户可读写的权限（Linux `0600`），包括重写曾被放宽权限的已有文件。绑定增删、配置迁移和安装器的安装、升级与失败恢复均沿用这一规则；默认安装目录保留 `0700`。权限修复对所有配置保存生效，不依赖日志策略。

安装器为支持的新版本通过标准输入传递面板令牌，不将令牌放进配置生成子进程的命令行参数。显式选择不支持此能力的历史版本时，保留旧参数以维持回滚兼容；历史版本不具备这项加固。手工执行安装命令时，也应避免将真实令牌写在命令行或保存在 Shell 历史中。

文件权限限制普通系统账号读取，不阻止宿主机管理员检查文件、进程或内存。改名和停用日志不提供反检测能力，也不自动删除历史日志。

## 独立面板入口

Agent 已支持独立的面板连接地址，在已有面板配置中更改地址即可，保留其余身份和节点设置：

```yaml
panel:
  url: https://agent.example.com
```

此域名必须实际提供面板的节点接口，例如通过独立域名和 HTTPS 反向代理接入原面板；只更改配置文字不会创建入口。HTTP 接口和 `/ws` 长连接都需要可用。面板设置了自定义节点长连接地址时，也应使用这个独立入口；未设置时，面板按请求的协议和域名生成长连接地址。

机器或节点身份不变，不需要另建一套面板。该设置独立于用户订阅域名和管理页面域名，不要求停用运行日志。
