# 隐私保护模式与独立面板入口

Agent v2.51.0 取消运行日志正文自动隐藏，但隐私保护模式完整保留：本地日志与待上传缓存仍加密，终端仍保持静默，密钥管理和保护策略不变。日志内容与文件加密是独立环节，正文规则见[日志管理](log-management.md#日志正文与隐私保护)。

Agent `v2.39.0` 起隐私保护模式改为加密记录，沿用已有开关和每台机器的文件密钥，不需要重建机器。本地候选 Agent `v2.40.0` 配套面板 `2.23.0` 优化日志保存及上传，尚未发布或部署。

在面板“服务器管理”中开启或关闭“隐私保护模式”并保存。开启时 Agent、节点及 Xray / sing-box 继续产生运行日志，逐条加密后保存到实例内核目录的 `runtime.log.enc`，不把这些记录写入终端、标准错误或服务日志。关闭后按本地等级和输出设置恢复普通日志；已有加密运行日志保持密文，不自动生成明文副本。

日志采用 AES-256-GCM 独立认证加密，文件格式为 `YZLOG1`，每条记录保存长度、密钥编号和密文，不保存密钥或启动凭据。单文件上限 20 MiB，保留三份旧文件（`.1` 至 `.3`）；写入失败、文件损坏或缺少历史密钥时保全原文件，不回退到明文输出。主配置无法加载时只返回固定启动失败阶段，不附带配置路径或异常正文。完整记录可通过 `privacy.State.ReadLog` 使用当前机器已领取的内存密钥读取，截断尾部会返回错误。轮转限制本地占用，面板保存期限另按各类日志设置执行。

Agent 运行日志上报继续使用独立的有界队列、加密缓存和固定批次重试，面板按“Agent 日志”的开关及保存期限记录警告、错误和致命错误。路由拦截记录正常保存，继续使用独立保存期限；访问记录、计费及状态功能沿用各自规则。

候选 `v2.40.0` 复用加密日志文件句柄，轮转、隐私关闭、重载及退出时关闭；每次追加仍检查外部替换、长度、修改时间和权限，损坏时保全原文件。待上报缓存只在记录、批次、文件状态或保护密钥变化时保存，固定批次和并发新增记录不会因跳过未变化保存而丢失。

配套面板通过握手声明最低上传等级为警告，节点在文本整理与入队前筛选较低等级，本地加密日志仍按原等级保存。已固定的待确认批次保留原记录和位置；旧面板未声明等级或返回未知等级时沿用原上传范围。格式、密钥和恢复机制不变，详见[日志优化验证](log-performance-optimization.md)。

首次取得策略前仍保持静默；已认证密钥接口返回的策略可用于启动记录，握手、发现和控制回报可立即切换日志出口，文件保护检查仍约每 20 秒运行。同一进程的已归属日志按实例和机器分别保存；无可靠归属的共享核心日志仅在本地写入配置顺序中首个已确认隐私身份的密文文件，不复制到各面板、不推测节点编号。只有单一可信身份时，共享 Xray 日志才上报面板。完整范围与兼容边界见[面板隐私模式](../../YZboard/docs/agent-log-policy.md)。

## 本地文件加密与自动恢复

开启后，Agent 通过原有机器或节点身份向面板领取该机器的文件密钥，使用 AES-256-GCM 加密程序管理的数据。密钥仅放在进程内存中，不保存到节点磁盘；这不是 SSH 公钥登录，也不需要手工在节点填写私钥。配置中的面板入口、身份、凭据引用，以及启动、健康检查和防火墙所需信息保留可读，服务重启后凭这些信息自动领取密钥。

保护范围包括每个实例的敏感配置、程序管理目录内的证书与证书私钥、ACME 状态、待确认流量、访问记录和历史运行日志队列、机器流量累计状态，以及位于该实例内核目录内的自定义配置。安装摘要仅保留必要的版本和实例信息，不再重复保存面板入口。由用户单独指定、放在这些目录外的共享证书或配置文件不会被自动改写。

Agent `v2.28.1` 中，Xray 和 sing-box 的自定义配置在启动及重载校验时也通过解密读取，支持 JSON 和 YAML。加密豁免仅限已登记的主配置路径及其同目录的 `credentials.env`、`install-meta.json`；内核目录中的 `config.yml` 或其他同名受管理文件不会因文件名相同而跳过加密。

已存在的受管理文件会原地迁移，保留原有数据；重复迁移不会重新累计流量或改变重试编号。各实例分别加密，一个面板暂时不可用时其他实例仍可恢复。正在运行的实例可继续使用内存中的密钥，冷启动则需要面板可达；暂时失败会保留文件并自动重试，不回退到明文运行。相同进程中不同机器不能使用重叠的数据目录，也不要为不同隐私策略的实例共用敏感默认值。

关闭时，Agent 使用原密钥自动还原实例配置、受管理目录内的加密文件及可确认身份的配置备份，再恢复明文保存；独立格式的加密运行日志不参与还原。转换使用文件写入屏障，旧运行实例不能在切换期间重新加密文件；保留原流量、待确认报告和未知扩展配置。转换失败保留未完成文件和启动恢复信息，并自动重试。面板在关闭状态下仍允许原认证身份领取恢复密钥，因此关闭后尚未完成转换就整机重启也能恢复；整机自动启动需要服务已启用开机自启。外部手工指定的共享文件仍不自动改写。

Agent 每约 20 秒检查文件保护策略，主配置变化沿用现有自动重载流程；日志策略在后续面板交换时应用。旧 Agent 仍可能停用隐私模式下的运行日志；需要配套新 Agent 才会继续产生加密运行日志。

密钥领取默认要求 HTTPS 面板入口，本机回环测试地址除外。`v2.51.2` 起也接受安装时由用户手动确认的 HTTP 入口：安装器提示认证令牌、配置和文件密钥的明文传输风险，确认后按实例保存对应地址；文件保护和恢复使用同一确认，仍保留本地文件加密。确认不扩散到其他入口，HTTPS 证书校验和密钥接口的跳转限制保持启用。安装确认流程见[安装说明](installer-output.md#http-面板确认)。

面板必须先升级到配套版本：旧面板已开启隐私保护、但不支持文件密钥时，Agent 停止受影响实例并等待恢复；未开启模式的旧面板继续沿用旧行为。

启动凭据 `credentials.env` 仍需供服务管理器读取，使用 `0600` 权限。复制单独的加密文件不包含密钥；取得完整节点目录及有效认证凭据的人仍可能向面板领取密钥。普通 LXC 的宿主机管理员也可检查进程内存，本功能不保证对宿主机保密。

### 面板备份与维护

面板按机器编号和自己的应用主密钥派生文件密钥，不把应用主密钥交给 Agent。恢复面板必须保留原数据库身份和 `APP_KEY`；轮换应用主密钥时，在 `APP_PREVIOUS_KEYS` 中保留仍有数据使用的旧密钥，待配置、所需备份迁移完成，且使用旧密钥的加密日志已轮转或移除后再移除。加密日志不会自动重写历史密钥。丢失必要的历史密钥会使对应文件无法解密。普通令牌轮换不改变文件密钥，但节点仍需有效的启动凭据。不要删除、重建机器来代替编辑。

绑定增删、升级和配置目录迁移继续使用现有维护入口。安装备份中能够确认属于当前身份且具有可恢复认证信息的配置也会加密；无法确认或缺少恢复条件的历史备份保留原样，需要用户另行保管。

显式选择不支持加密的历史版本时，新程序先生成兼容配置，并在停止服务后恢复旧程序需要的数据；失败回滚也先转换恢复快照。无法取得必要密钥时，停止降级，保留当前程序、数据及恢复文件，并尝试重新启动当前服务。历史版本没有这项加密能力，也不能保证继续执行永久停用日志策略。

## 敏感文件权限

配置、凭据及安装记录在保存时使用仅所属用户可读写的权限（Linux `0600`），包括重写曾被放宽权限的已有文件。绑定增删、配置迁移和安装器的安装、升级与失败恢复均沿用这一规则；默认安装目录保留 `0700`。权限修复对所有配置保存生效，不依赖日志策略。

安装器为支持的新版本通过标准输入传递面板令牌，不将令牌放进配置生成子进程的命令行参数。显式选择不支持此能力的历史版本时，保留旧参数以维持回滚兼容；历史版本不具备这项加固。手工执行安装命令时，也应避免将真实令牌写在命令行或保存在 Shell 历史中。

文件权限限制普通系统账号读取，不阻止宿主机管理员检查文件、进程或内存。改名和停用日志不提供反检测能力，也不自动删除历史日志。

## 独立面板入口

Agent 已支持独立的面板连接地址，在已有面板配置中更改地址即可，保留其余身份和节点设置：

```yaml
panel:
  url: https://agent.example.com
```

此域名必须实际提供面板的节点接口，例如通过独立域名和 HTTPS 反向代理接入原面板；只更改配置文字不会创建入口。HTTP 接口和 `/ws` 长连接都需要可用。面板设置了自定义节点长连接地址时，也应使用这个独立入口；未设置时，面板按请求的协议和域名生成长连接地址。

机器或节点身份不变，不需要另建一套面板。该设置独立于用户订阅域名和管理页面域名，不要求改变日志设置。
