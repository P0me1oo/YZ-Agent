# Lite 接管主机监控

YZ-Agent v2.35.0 配套面板 2.9.0，通过布尔字段 `host_monitoring` 控制通用主机采集。服务器绑定 Lite 且接入已启用时为 `false`；解绑、关闭 Lite 或未绑定时为 `true`。旧面板成功响应缺少此字段时恢复原采样，通信失败保留已确认策略。

策略入口包括握手、机器节点发现、每 5 秒的机器控制交换，以及 HTTP/WebSocket 实时状态回执。机器模式中所有节点读取同一机器客户端的策略，节点迟到回执不会覆盖它；空机器继续发送控制及实时心跳，不依赖有代理节点才能恢复。

关闭时不再调用主机采集器读取 CPU、每核占用、系统负载、内存、交换区、磁盘和通用网卡速度，也不做启动时无条件预采样。旧报告、实时状态和旧 WebSocket 节点指标全部遵循此策略；发送前再次剔除主机字段，避免切换后重试原批次。缺失的主机指标不作为零值发送。

代理流量、在线/连接/来源 IP/设备状态、限速事件、核心和运维状态、控制心跳以及进程运行时长/协程/GC 保持。服务器流量保护的独立计量不受此开关影响。解绑或停用后按原采样周期恢复，无需重启 Agent；Lite 本身不可达不会自动开启重复采集。

面板同时拒绝保存绑定服务器的主机负载和新增负载历史，因此旧 Agent 仍上报时也不会继续写历史。完整停止采集需要配套升级 Agent。详情见[面板 Lite 接入](../../YZboard/docs/lite-monitor.md)。
